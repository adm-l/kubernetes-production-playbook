# Kubernetes Production Playbook

A practical, reusable reference for designing, deploying, operating, securing, scaling, and troubleshooting Kubernetes workloads. The repository is being built out in stages; see the roadmap and safety notes as files are added.

> **Safety:** These manifests are reference templates, not universal production defaults. Review image names, resource sizing, network access, secrets, storage, cloud integrations, and cluster policies before applying them. Never commit real credentials.
